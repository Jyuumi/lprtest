    <h1>lprtest</h1>

<div align="center">
<h2>Linux Partition Reliability Test Tool</h2>
</div>

- lprtest is based on some reverse engineering of urwtest and aims to allow Linux users to test the reliability of partitions.

- lprtest may not be compatible with the kernel version, distribution or file system you are using.
